# Trackbeez Calculator Suite

A modern, feature-rich calculator suite built with Flask that combines multiple calculator functionalities in one web application.

## 🌟 Features

### 🧮 Scientific Calculator
- Full-featured calculator with scientific functions
- Real-time calculations
- Keyboard support
- Memory functions
- Scientific operations (sin, cos, tan, log, ln)

### 📈 Graphing Calculator
- Interactive function plotting
- Support for mathematical expressions
- Customizable graph ranges
- Special feature: Animated Love Heart graph ❤️
- Real-time graph updates

### 🔢 Matrix Calculator
- Matrix operations:
  - Addition
  - Multiplication
  - Transposition
- Dynamic matrix size adjustment
- Visual matrix input interface
- Real-time validation

### ⚖️ Unit Converter
- Length conversion (meters to feet)
- Weight conversion (kilograms to pounds)
- Temperature conversion (Celsius to Fahrenheit)
- Conversion history
- Real-time conversion

### ✏️ AI Drawing Calculator
- Hand-drawn mathematics recognition
- Step-by-step solution display
- Powered by Google's Gemini AI
- Drawing history
- Export functionality

## 🚀 Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/trackbeez-calc.git
cd trackbeez-calc
```

2. Create and activate virtual environment:
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
```

3. Install dependencies:
```bash
pip install -r requirements.txt
```

4. Set up environment variables:
```bash
# Create .env file and add:
GEMINI_API_KEY=your_api_key_here
```

5. Run the application:
```bash
flask run
```
