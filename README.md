# Multi-Function Calculator

A versatile calculator application built with Streamlit that combines multiple calculator functionalities in one web application.

## Features

- **Scientific Calculator**: Full-featured calculator with scientific functions
  - Basic arithmetic operations
  - Scientific functions (sin, cos, tan, log, etc.)
  - Constants (π, e)
  - Memory functions

- **Graphing Calculator**:
  - Plot mathematical functions
  - Interactive graph manipulation
  - Special feature: Animated Love Heart graph ❤️

- **Matrix Calculator**:
  - Matrix addition
  - Matrix multiplication
  - Matrix transposition
  - Support for various matrix sizes

- **Unit Converter**:
  - Length (meters to feet)
  - Weight (kilograms to pounds)
  - Temperature (Celsius to Fahrenheit)
